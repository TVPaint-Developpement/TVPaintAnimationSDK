How to enable a meta-function ?

 

This section explains how to enable a metafunction.
Metafunctions allows you to use a shape (line, circle, ....) in your plugin for setting a position, a distance, ... in your project.
When the metafunction is installed, it takes the "drawing handle" and deselect the current shape.
If the metafunction is installed and you select a shape in the TVPaint main panel, it closes the metafunction.
The metafunction MUST be closed before exiting TVPaint, because it could crash the process.
So the message PICMETA_CLOSE is send when :

  • a shape is selected,
  • the function TVCloseFunction() is called. 
static int meta=0;   

/*******************************************************/

int FAR PASCAL PI_Msg(PiFilter *PiFilter, DWORD fonc, DWORD req, DWORD *tag)
{
	switch(fonc)
	{
		case PICBREQ_BUTTON_UP:
		{
			case BUTTON_META:		/* if the button which enable the metafunction is pressed */
			{
				if(meta==0)			/* The metafunction was not opened */
				{
					meta=1;
					TVInstallFunction (PiFilter, PIDRAW_DRAW);		/* We install the metafunction (PIDRAW_DRAW in our case) */
				}
				else
				if(meta==1)			/* The metafunction was opened */
				{
					TVCloseFunction(PiFilter);		/* We close the metafunction */
				} 
			}
			break;
		}
		break; 
 
		case PICMETA_CLOSE:			/* The metafunction is closed */
		{
			meta=0;
		}
		break;
			
		case PICMETA_DRAW:			/* The metafunction is open */
		{
			...						/* Do your job ! */
		}
		break;

		case PICBREQ_CLOSE:			/* The plugin windows in closed */
		{
			if(meta!=0)				/* If the metafunction was opened */
			{
				TVCloseFunction(PiFilter);
			}
		}
		break;

	.... 
   }
}
