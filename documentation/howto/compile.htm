How to compile a plugin ?

 

TVPaint plugins are normal windows DLLs.

First :

Configure your development environment to link the plugin with sources/dllx.c.

Second :

Add the "include" directory to your compiler's include directories.

Third :

Export these symbols in your linker :

PI_Msg
PI_Open
PI_About
PI_Parameters
PI_Start
PI_Work
PI_Finish
PI_Close
PI_SequenceStart
PI_SequenceFinish

And export these symbols too for a preview plugin :

PI_MakePrevAnim
PI_PlayPrevAnim
PI_RemovePrevAnim

Look at the sample .def files in the examples directories.

Fourth :

Compile… Wait… and Enjoy !
