How to localize your plugin ?

 

This section explains how to localize your plugin. Localization allow you to put your plugin text in a external file, which could be translated.
There are a few precautions when you localize your plugin :

    1. First, the text position could be different because of a different text size, so you must use specific text function like TVChangeButtonName(), look in the here.
    2. Then, don't forget to include in your source code a default text in case the localization file is missing. 
static void *LocalFile;


/*******************************************************/ 

#define TXT_NAME GetLocalString(PiFilter, 100,  "Default")		/* The text has the text number 100. The default text is "Default" */

/*******************************************************/

static char *GetLocalString(PIFilter * PiFilter, int num, char *def)		/* This function reads the text number in the loc file */
{
char *str;

	if(LocalFile==NULL)return def;		/* If the loc file doesn't exist, it returns the default text (char *def) */
	
	str=TVGetLocalString(PiFilter, LocalFile, num);

	if(str==NULL || strlen(str)==0)return def;		/* If the number doesn't exist, it returns the default text (char *def) */
	
	return str;
}
