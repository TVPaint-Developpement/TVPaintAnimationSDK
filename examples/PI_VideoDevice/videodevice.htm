Video Device

This example show how to connect a Video device to the TVPaint Input (to grab or display a video stream) and/or to the Output (to send TVPaint projects to a frame buffer or an external application). In this example we created a video noise as an input signal. And the display device opens an TVPaint requester to simulate a frame buffer. This example shows also how to use the Fit function (to stretch a VideoBlock at the right size) and the Key function (to overlay an TVPaint project over a video stream).
