Image Printer

 

This plugin allows you to export as a C file your image brush. It's very usefull to include images in your plugin (buttons, logo, ...).

 

Options :

Compress : Pack your brush in RLE format (Saves a lot of space for the dll !).
Add C code : Add at the end of the C file the function GetImage() which returns the image in a newly allocated PIBlock.
